## Datos clave para recordar

- **SAM real**: USD 450M/año (tooling PPC para PyMEs LATAM)
- **Beachhead**: E-commerce chicos Argentina (~150K negocios)
- **Pain**: 62% quiere dejar Google Ads, 56% tiene <1h/día para marketing
- **Margen bruto**: ~85%
- **LTV:CAC**: 6:1 – 9:1 (benchmark saludable: 3:1)
- **Breakeven**: 13 clientes (mes 2-3)
- **Inversión mínima**: USD 1,030
- **MVP**: 27 módulos, Google Ads API v16, IA multi-provider, construido con USD 0

## Respuestas rápidas Q&A (ver red-team.md para versiones completas)

- **"¿Google te mata?"** → Conflicto de intereses. Google quiere que gastes más, nosotros mejor
- **"¿Moat?"** → Data flywheel. 1,000 campañas LATAM = dataset irreplicable
- **"¿Primeros 100 clientes?"** → Agencias. 5 agencias > 100 PyMEs individuales
- **"¿Por qué LATAM?"** → 0 herramientas en español. Preferimos ser #1 en LATAM que #51 en USA
- **"¿IA quema plata?"** → 3 capas: guardrails, monitoreo 24/7, pausa automática
- **"¿OpenAI sube precios?"** → Multi-provider ya integrado. LLM es commodity
