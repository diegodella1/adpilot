Documentación completa — Funcionalidades, API y configuración

Setup inicial

  1. Haz clic en “Primer uso? Crear admin” en la pantalla de login.
  2. Configura el proveedor LLM (OpenAI o OpenRouter) con su API key y modelo en Admin.
  3. Configura las credenciales de Google Ads (Client ID, Secret, Developer Token, Refresh Token, Customer ID).
  4. Sin Google Ads, AdPilot funciona como copiloto: genera estructuras de campaña para crear manualmente.

Módulos de la plataforma

Chat — Creación de campañas

Describe tu campaña en lenguaje natural. El agente IA guía paso a paso, genera la estructura completa en JSON y la ejecuta en Google Ads. Soporta Search, Performance Max, Display y Video.

Campañas — Gestión de campañas activas

Panel completo para ver y editar campañas activas: presupuesto, bidding, geo-targeting por ciudad, keywords, negative keywords, audiencias, device bids, UTMs. Todo inline sin entrar a Google Ads.

Dashboard — Métricas en tiempo real

KPIs globales (spend, clicks, conversiones, CPA, CTR, ROAS), gráfico de tendencia, tabla de campañas con alertas automáticas. Sincronización on-demand desde Google Ads.

Analizar — Chat de optimización

Chat con IA especializado en análisis de rendimiento. Accede a métricas, identifica problemas y ejecuta acciones de optimización directamente desde la conversación.

Reglas — Motor de automatización

Reglas condicionales que evalúan métricas y ejecutan acciones automáticamente o con aprobación. Soporta pausar/activar a nivel campaña, ad group y ad, cambiar bidding, agregar negativas, ajustar device bids y más.

Keywords — Investigación

Ideas de keywords desde Google Ads Keyword Planner con volumen de búsqueda, competencia y CPC estimado.

Knowledge — Base de conocimiento

Base vectorial con embeddings que se alimenta automáticamente de cada campaña y optimización ejecutada.

Admin — Configuración

Credenciales (encriptadas AES-256), proveedor LLM, master prompt, business context, gestión de usuarios con límites de consumo.

Gestión de campañas activas

Geo-targeting por ciudad

Targeting geográfico granular: países completos (código ISO) y ciudades específicas (location IDs de Google Ads).

  • GET /api/locations/search?q=miami — Buscar ciudades (retorna criterion ID)
  • PUT /api/campaigns/:id/geo-targets — Reemplazar geo targets con { targets: [1023191, 1016367] }
  • En creación, el LLM puede mezclar: geo_targets: ["US", 1023191]

Presupuesto, bidding y status

  • PUT /api/campaigns/:id/budget — { budget_micros: 50000000 } ($50/día)
  • PUT /api/campaigns/:id/bidding — { strategy: "TARGET_CPA", value_micros: 5000000 }
  • PUT /api/campaigns/:id/status — { status: "PAUSED" | "ENABLED" }
  • Strategies: TARGET_CPA, MAXIMIZE_CONVERSIONS, MAXIMIZE_CLICKS, TARGET_ROAS

Keywords y negative keywords

  • POST /api/campaigns/:id/ad-groups/:agId/keywords — Agregar keywords con match type
  • DELETE /api/campaigns/:id/ad-groups/:agId/keywords/:kwId — Eliminar keyword
  • POST /api/campaigns/:id/ad-groups/:agId/negative-keywords — Agregar negativas

UTM Tracking

Aplicar o cambiar UTMs en campañas activas. Los ads RSA de Google son inmutables: AdPilot crea ads nuevos con las URLs actualizadas y pausa los anteriores automáticamente.

  • PUT /api/campaigns/:id/utm — { utm_params: { source, medium, campaign, content, term } }
  • Soporta macros de Google Ads: {keyword}, {campaignid}

Audiencias, device bids y remarketing

  • GET /api/audiences/search?q=investing — Buscar segmentos (In-Market, Affinity)
  • POST /api/campaigns/:id/audiences — Agregar en modo observación
  • PUT /api/campaigns/:id/devices — { adjustments: { desktop: 1.0, mobile: 0.8 } }
  • POST /api/campaigns/:id/remarketing — Agregar lista de remarketing

Seguridad

  • Credenciales encriptadas con AES-256 en base de datos
  • Autenticación JWT con expiración de 24 horas
  • Rate limiting: 120 req/min global, 15 req/min para endpoints LLM
  • Multi-tenant con aislamiento completo por usuario
  • Límites de consumo LLM configurables por usuario
  • Headers de seguridad: X-Content-Type-Options, X-Frame-Options, Referrer-Policy
  • Protección contra prompt injection en el system prompt del LLM
  • Rollback automático de campaña si todos los ad groups fallan
Stack: Node.js + Express + Supabase + pgvector  |  LLM: OpenAI / OpenRouter  |  API: Google Ads API v18  |  Auth: JWT + bcrypt
